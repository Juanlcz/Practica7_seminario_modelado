# Simulación de Motor DC (MATLAB / Simulink)

Simulación de un motor de corriente continua utilizando un modelo en espacio de estados.  
El sistema se implementa en MATLAB usando `ode45` y también en Simulink/Simscape.

Archivos incluidos:
- `Motordc.m` – Modelo dinámico del motor DC.
- `main.m` – Ejecuta la simulación y grafica posición, velocidad y corriente.
- `motordc.slx` – Implementación del modelo en Simulink/Simscape.
